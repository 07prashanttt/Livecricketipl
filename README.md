# PRASHANT IPL AUCTION 3D — 3D Match Engine Foundation

This folder is a playable 3D cricket match foundation using Three.js and JavaScript ES modules.

## GitHub setup
1. Open your repository `PRASHANT-IPL-AUCTION-3D`.
2. Upload/replace the files while preserving a backup of your current project.
3. Add the `engine` folder and its two files exactly as shown.
4. Commit the changes.
5. Open **Settings → Pages** and ensure Pages deploys from your main branch/root.
6. Open the published URL in Chrome. If an old version appears, refresh the page or clear the site cache.

## Controls
- Switch to **BOWLING**, choose line/length/pace, tap **BOWL**.
- Switch to **BATTING**, tap DEFEND / GROUND / LOFT / SWEEP as the ball travels.
- Keyboard: Space or B = bowl; 1 = defend; 2 = ground; 3 = loft; 4 = sweep.
- This starter match is 2 overs per innings so it can be tested quickly.

## Important
- Three.js is loaded from jsDelivr, so the first load requires an internet connection.
- This is a playable prototype foundation, not a finished commercial 3D cricket game.
- The current match engine uses simplified cricket outcomes. It does not yet contain full official IPL rules, full player animations, licensed player likenesses, team logos, tournament schedule, or integration with your existing auction data.
- Keep your existing project backed up before replacing files. This starter's `index.html`, `style.css`, and `app.js` create a separate 3D match screen.
